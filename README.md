# Aakib-portfolio

Portfolio site for Akib Sayyad — multi-disciplinary artist & illustrator. Built with Next.js (App Router), Tailwind CSS v4, Framer Motion and Lenis smooth scroll.

## Deploy

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FGaurav6321%2FAakib-portfolio)

No environment variables or settings are needed — Vercel detects Next.js and builds it as is. The free Hobby plan is enough.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Editing content

- `lib/data.ts` — projects (title, Behance link, image), bio, skills, brands, social links.
- `public/projects/` — project cover images.
- `public/akib.jpg` — portrait used on the home and about pages.
